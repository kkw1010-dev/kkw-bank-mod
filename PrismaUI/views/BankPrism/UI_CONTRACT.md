# BankView.html 인터페이스 계약

이 폴더의 `BankView.html`은 게임과 두 방향으로 통신한다. **모양은 얼마든지 바꿔도
되지만, 아래 계약을 깨면 UI가 아니라 모드 전체가 동작하지 않는다.**

디자인만 손보는 경우 이 문서의 내용만 지키면 되고, Papyrus나 C++는 건드릴 필요가
없다.

## 1. 게임 → UI

게임이 이 함수를 호출한다. **이름을 바꾸면 안 된다.**

```js
window.bankUpdateParams(jsonString)
```

넘어오는 JSON의 필드는 다음과 같다. 전부 매번 들어온다.

| 필드 | 형 | 의미 |
| --- | --- | --- |
| `wallet` | 정수 | 플레이어 소지금 |
| `balance` | 정수 | 이 홀드에 맡긴 금액 |
| `debt` | 정수 | 이 홀드의 대출 잔액 |
| `creditDebt` | 정수 | 이 홀드의 외상 잔액 |
| `loanLimit` | 정수 | 대출 한도. 0이면 대출 불가 |
| `loanDaysLeft` | 정수 | 만기까지 남은 일수. 음수면 지난 것 |
| `overdueDays` | 정수 | 연체 일수. 0이면 연체 아님 |
| `grade` | 문자열 | 신용등급 (신뢰 / 우량 / 양호 / 보통 / 주의 / 불량) |
| `hold` | 문자열 | 홀드 이름 (화이트런 등) |
| `holdKey` | 문자열 | 배경 이미지 파일명 (`whiterun` 등) |
| `txType` | 문자열 | 방금 성사된 거래 종류. 없으면 빈 문자열 |
| `txAmount` | 정수 | 그 거래 금액 |
| `message` | 문자열 | 화면에 띄울 안내 문구 |

`txType`이 비어 있지 않을 때만 거래 기록에 한 줄을 추가한다. 값은
`deposit` / `withdraw` / `borrow` / `repay` / `payCredit` 중 하나다.

## 2. UI → 게임

버튼을 누르면 이 함수를 호출한다. **이름을 바꾸면 안 된다.**

```js
window.bankAction(payload)
```

`payload`는 문자열이며 두 가지 형식뿐이다.

```
"close"              금액이 없는 동작
"deposit:500"        금액이 필요한 동작은 콜론 뒤에 정수
```

보낼 수 있는 동작은 다음이 전부다. 이 외의 문자열은 게임이 무시한다.

| 동작 | 금액 | 의미 |
| --- | --- | --- |
| `deposit` | 필요 | 입금 |
| `withdraw` | 필요 | 출금 |
| `borrow` | 필요 | 대출 실행 |
| `repay` | 필요 | 대출 상환 |
| `payCredit` | 불필요 | 외상 상환 |
| `sellBond` | 불필요 | 채권 매각 (미구현) |
| `close` | 불필요 | 창 닫기 |

## 3. 반드시 남겨야 하는 것

- **`window.bankUpdateParams`와 `window.bankAction` 두 이름.** 게임이 이 이름으로
  찾는다
- **배경 이미지 경로는 `bg/<holdKey>.jpg` 상대경로.** 홀드마다 다른 그림이 깔린다
- **닫기 버튼.** `close`를 보낼 수단이 없으면 창을 닫지 못한다

## 4. 하면 안 되는 것

- **텍스트 입력창(`<input type="text">` 등)으로 금액을 받지 말 것.** 게임이
  일시정지된 상태에서는 키보드 입력이 이 화면에 전달되지 않는다. 금액은 버튼으로
  만든다
- **외부 리소스를 불러오지 말 것.** 폰트, CDN, 이미지 URL 모두 안 된다. 게임 안
  브라우저라 네트워크가 없다. 필요한 파일은 이 폴더에 두고 상대경로로 쓴다
- **`alert()`를 쓰지 말 것.** 렌더러에 없는 함수다. 안내는 화면 안에 표시한다

## 5. 고쳐도 되는 것

레이아웃, 색, 글꼴 크기, 탭 구성, 애니메이션, 요소의 `id`와 클래스 이름 —
**JS를 함께 고치는 한 전부 자유다.** `id`는 이 파일 안에서만 쓰이므로 게임과는
무관하다.

## 6. 고친 뒤에

저장소 최상위에서 배포 스크립트를 돌려야 게임에 반영된다.

```
powershell -File deploy.ps1
```

HTML만 고쳤다면 이것만 하면 되고, 게임은 다시 켜야 한다.
